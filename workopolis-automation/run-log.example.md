# Workopolis — run log

This channel holds ONLY its logs. **Every form answer comes from the single bank `bank/core.md`** —
there is no per-site answer bank. §5 = unanswered questions; §6 = this channel run log (the source of
the per-day submission cap).

> **This file is a template.** Copy it to `run-log.md` before a run:
>     cp workopolis-automation/run-log.example.md workopolis-automation/run-log.md
> `run-log.md` is git-ignored, so your application history is never committed.

Channel mechanics and site-specific facts live in `RULESET.md`.
