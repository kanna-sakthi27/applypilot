# LinkedIn Premium — tailor-resume notes

Discovered controls for LinkedIn Premium's per-application **"tailor / customise your resume"**
option live here, so a later run does not have to rediscover them.

The `linkedin` prompt asks a run to append a line here whenever it finds a working control
(text / aria label / selector) for the tailor-resume option, keyed by what it saw.

## Format

| Date | Control (exact text / aria) | Selector | Notes |
| --- | --- | --- | --- |
| <YYYY-MM-DD> | "<visible button text>" | "<selector>" | <where it appears, any caveats> |

## Known caveats

- The option is not shown on every posting; it can be market- or account-gated.
- If it is absent, use the canonical resume and continue. **Never skip a job because tailoring is
  unavailable.**
